# Alpha 107: UV drag preview and Quake II WINDOW compilation

## UV editor

Texture dragging now updates a temporary UV preview. It does not delete/recreate the brush or invalidate the map geometry on each mouse movement. Releasing the gesture commits one brush update and one Undo step. Cancel leaves the original mapping and Redo history intact. Numeric material fields follow the preview.

This applies to the UV canvas transform commands: offset, scale, rotation and shear. It does not claim that every material operation or the final commit is free of cost.

## Quake II compilation

The editor previously combined its inferred SOLID default with explicit WINDOW contents while reading a Quake II MAP. That produced `Mixed visible contents: SOLID | WINDOW` in ericw-tools QBSP. Explicit Quake II contents now replace that inferred default.

For previously affected files, compilation also removes the legacy SOLID bit from the exact SOLID | WINDOW conflict in the disposable compiler input, preserving other contents bits, surface flags and values. The compile log reports this repair. The source MAP is not rewritten. Other conflicting contents combinations are preserved for diagnosis.

## Verification

- Windows and Linux runtime UV checks: offset, rotation, Valve 220 shear, singular-matrix rejection, cancellation preserving Redo, Repeat, one-step Undo and unchanged geometry/history throughout 240 preview updates.
- Standalone contents parser tests cover classic and Valve 220 syntax, detail flags, comments and unrelated conflicts.
- A small WINDOW test room reproduced the original QBSP failure before the change and compiled after the parser fix and after repairing an old exported copy. The user's D: drive map was not available for a full-map reproduction.

## Please check

1. On a large map, select one face and drag, rotate and scale its UV mapping. Check both the UV canvas and the 3D surface during the gesture.
2. Release, Undo and Redo. Cancel another gesture and confirm the original mapping returns.
3. Check numeric offsets/scales/angle while dragging, plus snapping and zoom.
4. Reopen the affected Quake II MAP and compile it with the same profile. If legacy flags need repair, look for the repair message in the compile log.
5. Confirm glass retains its surface flags/transparency and that unrelated solid brushes remain intact.

Missing mod textures remain a separate resource issue. This change does not reconstruct unavailable images.
