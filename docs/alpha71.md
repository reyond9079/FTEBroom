# ReyondBroom alpha 71

The ordinary desktop editor gains a [Model editor](model-editor.md), opened
from a model's context menu in the Mod file manager.

- Preview on the left, resizable transform inspector on the right.
- Numeric position, rotation, size, per-axis scale and Total scale.
- Move arrows, rotation rings, scale handles, mesh parenting and reset.
- Highlighted world origin and reference axes.
- Triangle Play/Pause button, animation/skin selection and bones overlay.
- Textured, untextured, wireframe and static player-perspective views.
- Export transformed geometry and diffuse textures through five writers:
  MD3, Quake MDL, OBJ, IQM and MD5MESH. Export limitations are shown before saving.

This is not the experimental online edition. Windows, native Linux and Linux
SDL2 use the same model editor implementation. See the guide for a detailed
verification checklist and format limitations.
